**Goal:** Admit and invoke all seven native Garden graph tools through AnimaOS with their full schemas and current authority checks.

**Architecture:** Keep Mother canonical contracts and credential-bound surfaces. In AnimaOS separate raw JSON/payload limits from bounded acyclic schema-reference traversal. Retain 16 KiB per schema, 32 KiB complete descriptor, 16-level/1,024-node raw JSON and argument bounds, and existing result/wire limits. Permit separately bounded expanded schema traversal (64 levels/8,192 visits). Input/output schemas share the existing complete-descriptor cap instead of the argument-size cap.

**Alternatives:** Opaque or weakened provider schemas discard constraints; provider-name exceptions couple generic admission to one service; raising all JSON bounds affects runtime payloads. Choose generic, separately bounded schema metadata processing and retain exact descriptor digests and owner review.

**Runtime finding:** Portable `DataValue` whole numbers previously serialized as
floating-point JSON and failed typed integer provider requests. Use one checked
safe-number converter for byte preflight and transport serialization. Fractions
retain their value; non-finite and unsafe integers remain rejected. Qualify
actual `ToolExecutionContext` dispatch, not only direct JSON manager calls.
